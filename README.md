# Orionex Members

Django application for member profiles, event registration, guest invitations,
attendance, announcements, and community messaging.

## Project layout

- `config/` contains Django settings, URL routing, and ASGI/WSGI entry points.
- `core/` contains the member app: models, views, forms, permissions,
  migrations, templates, static source files, and management commands.
- `templates/` contains project-wide template overrides, including admin
  branding.
- `members.xlsx` is the source spreadsheet for the `import_members` command.
- `staticfiles/` is generated by `collectstatic` for deployment; edit source
  assets under `core/static/` instead.

## Run locally

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

For production, set `DJANGO_DEBUG=false`, `DJANGO_SECRET_KEY`,
`DJANGO_ALLOWED_HOSTS`, a PostgreSQL `DATABASE_URL`, and email settings.

Before deployment, collect static assets with `python manage.py collectstatic --noinput`.

To import a workbook, run `python manage.py import_members <path-to-workbook>`.
