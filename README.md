# Orionex Members

Django application for member profiles, event registration, guest invitations,
attendance, announcements, and community messaging.

## Project layout

- `config/` contains Django settings, URL routing, and ASGI/WSGI entry points.
- `core/` contains the member app: models, views, forms, permissions,
  migrations, templates, static source files, and management commands.
- `templates/` contains project-wide template overrides, including admin
  branding.
- `members.xlsx` is the source spreadsheet for the `import_members` command.
- `staticfiles/` is generated by `collectstatic` for deployment; edit source
  assets under `core/static/` instead.

## Member and club features

- Project teams, task assignments, priorities, deadlines, and monthly or weekly
  calendar views are available to signed-in members.
- Notifications cover new and changed events, announcements, RSVP confirmations,
  task assignments, and upcoming event or task reminders.
- Members can submit event feedback, share links and PDF or PowerPoint learning
  resources.
- Staff with member management access can review join applications. Event
  managers can review feedback, view monthly, yearly, and all-time analytics,
  and track budget entries.
- Public pages include club information, team roles, past and upcoming events,
  completed projects, a media gallery, partners, and membership applications.
- Public content is managed through the Orionex admin area. Resource file
  downloads require a signed-in member; accepted files are limited to PDF/PPT/PPTX
  and 15 MB.

## Run locally

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

For production, set `DJANGO_DEBUG=false`, `DJANGO_SECRET_KEY`,
`DJANGO_ALLOWED_HOSTS`, a PostgreSQL `DATABASE_URL`, and email settings.

Before deployment, collect static assets with `python manage.py collectstatic --noinput`.

To import a workbook, run `python manage.py import_members <path-to-workbook>`.
